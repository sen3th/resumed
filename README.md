## Resumed
Resumed is a resume builder made with vanilla html, css and javascript.

# Local Development
- Clone the repository.
- Open `index.html` in your browser or just use a live server extension.
- Tweak the code as you like :)

# Demo
You can use the [demo](https://resumed-s.netlify.app/) to test the resume builder without downloading it.

# Contributing
Feel free to contribute to the repository by submitting a pull request.
